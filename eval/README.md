# 라우팅 정확도 평가

라우터(`analyzers/experts/router.py`)가 고른 전문가의 정확도 측정용 골드셋과 채점 스크립트. 룰 단독 대비 룰과 임베딩 조합의 개선 여부 확인이 목적. 테마마다 `rule_pred`, `emb_pred`, `hybrid_pred`(운영 로직) 세 가지를 기록해 정답과 비교.

## 표집

- 모집단: 운영 브리핑 1,306개에서 기사 2건 이상인 고유 테마 3,793개 추출, 라우터 재실행
- 판정 분포: rule 70.6%, embedding 20.8%, 임베딩 교체(override) 8.7%. 운영 로그(69.2/22.6/8.2%)와 거의 동일
- 층화 사유: 무작위 200건이면 임베딩 교체 사례가 17건 내외에 불과. 판정 경로별 4개 층에서 50건씩 표집

| 층 | 뜻 | 모집단 | 가중치 |
|---|---|---|---|
| `S1_룰임베딩합치` | 룰과 임베딩 1위가 같음 | 1,213 | 24.26 |
| `S2_임베딩반대했으나룰유지` | 불일치했지만 마진 미달 | 1,463 | 29.26 |
| `S3_저신뢰라벨` | `general`/빈 라벨이라 임베딩이 결정 | 789 | 15.78 |
| `S4_뒤집음` | 임베딩 교체 | 328 | 6.56 |

## 라벨링 기준

- 라벨링 화면에 라우터 예측과 피드 카테고리 미표시
- 기준: 묶음의 주제가 어느 데스크 소관인지
- 판단 불가 시 `__ambiguous__`로 표시, 채점에서 제외

## 채점

```bash
python eval/score_routing.py eval/gold_labels.json
```

- 입력: `gold_labels.json`, `{"<theme_id>": "<expert_id>"}` 형식. 라벨링 완료 후 생성
- 산출: 표본 정확도와 층 가중치를 적용한 모집단 추정치, 두 기준으로 계산
  - 주 지표: 전문가 9종을 관점 그룹 6종(증권+경제, 정치+국제, 문화+스포츠를 하나로)으로 묶은 정확도. 사람이 라벨링해도 이 세 쌍은 경계가 모호하기 때문
  - 참고 지표: 9종 그대로 맞힌 비율
- 기타 출력: 층별 정확도, 임베딩 교체 적중률, 혼동 행렬, 그룹까지 틀린 사례
- `gold_sample.json`: 표집된 200건
