# 라우팅 정확도 평가

라우터(`analyzers/experts/router.py`)가 고른 전문가가 맞는지 재기 위한 골드셋과 채점 스크립트다. 궁금한 건 룰 + 임베딩 조합이 룰 단독보다 나은지라서, 테마마다 `rule_pred`, `emb_pred`, `hybrid_pred`(운영 로직) 세 가지를 기록해 정답과 비교한다.

운영 브리핑 1,306개에서 기사 2건 이상인 고유 테마 3,793개를 뽑아 라우터를 다시 돌렸다. 판정 분포(rule 70.6%, embedding 20.8%, override 8.7%)는 운영 로그(69.2/22.6/8.2%)와 거의 같다. 무작위 200건이면 override가 17건 정도밖에 안 들어와서 판정 경로별 4개 층에서 50건씩 뽑았다.

| 층 | 뜻 | 모집단 | 가중치 |
|---|---|---|---|
| `S1_룰임베딩합치` | 룰과 임베딩 1위가 같음 | 1,213 | 24.26 |
| `S2_임베딩반대했으나룰유지` | 불일치했지만 마진 미달 | 1,463 | 29.26 |
| `S3_저신뢰라벨` | `general`/빈 라벨이라 임베딩이 결정 | 789 | 15.78 |
| `S4_뒤집음` | 임베딩이 룰을 override | 328 | 6.56 |

라벨링 화면엔 라우터 예측과 피드 카테고리를 보여주지 않는다. 기준은 묶음의 주제가 어느 데스크 소관인가이고, 판단이 안 서면 `__ambiguous__`로 두고 채점에서 뺀다.

```bash
python eval/score_routing.py eval/gold_labels.json
```

`gold_labels.json`은 `{"<theme_id>": "<expert_id>"}` 형식이고 라벨링이 끝나면 생긴다. 스크립트는 표본 정확도와 층 가중치를 적용한 모집단 추정치를 두 기준으로 낸다. 주 지표는 전문가 9종을 관점 그룹 6종(증권+경제, 정치+국제, 문화+스포츠를 하나로)으로 묶은 정확도이고, 9종 그대로 맞힌 비율은 참고로 같이 찍는다. 사람이 라벨링해도 이 세 쌍은 경계가 흔들려서다. 그 밖에 층별 정확도, override가 맞은 비율, 혼동 행렬, 그룹까지 틀린 사례를 출력한다. `gold_sample.json`은 표집된 200건이다.
